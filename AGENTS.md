# Правила шаблона практики

- Единственный источник содержания — content/course.json. Не создавать рядом дополнительные версии example, demo, final или новый генератор того же комплекта.
- Одна практика — одно задание с этапами. Связь с другими практиками необязательна; при необходимости описывается в условии.
- Задание PDF содержит все обязательные условия, предметные области, проверки и сдачу. Инструкция с образцом — отдельный дополнительный PDF по решению преподавателя.
- Три раздела сайта: задание, инструкция с образцом, предметные области. Раздел «Преподавателю» не создавать: показ проходит в инструкции. Образец является частью инструкции; отдельная страница с теми же рисунками не нужна.
- Код хранится один раз в code. Части инструкции ссылаются на code_lines; не поддерживать несколько ручных копий.
- Не генерировать одинаковые пустые карточки. Добавлять только содержательно различные варианты в areas.
- PDF: A4, альбомный формат, понятные учебные страницы, полный читаемый код, нумерация. Статичные рисунки с подписями, без анимации.
- Одно действие за шаг, термин до первого использования, короткая теория рядом с действием и явная проверка. Не упоминать способности студентов.
- Не придумывать реквизиты, часы и официальные критерии. Перед выдачей преподаватель проверяет содержание и устанавливает meta.status=ready.
- Перед публикацией: python scripts/build.py и python scripts/check.py, просмотр страниц и PDF. Проверить успешность публикации.
- Сборка очищает только собственный site/ после проверки абсолютного пути. Старые генерируемые PDF не сохранять в публикации.
