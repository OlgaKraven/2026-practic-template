# Универсальный шаблон практики

[Открыть задание](https://olgakraven.github.io/2026-practic-template/)

Один комплект: **задание → инструкция с образцом → предметные области**. Раздел «Преподавателю» объясняет выдачу и адаптацию. Сайт предназначен для показа; студент получает PDF через учебную систему.

## Содержание

Единственный источник — `content/course.json`. Сейчас он содержит пример Unity «Счётчик собранных предметов» и два различных варианта. Для полноценной практики добавьте нужное число содержательных вариантов. Тридцать пустых копий больше не создаются.

- `assignment` — общая задача и приёмка.
- `areas` — индивидуальные условия.
- `guide` — теория, действия, статичные рисунки, код и проверка.
- `code` — единственная полная версия программы; фрагменты инструкции берутся по `code_lines`.
- `meta` — паспорт и версия материала.

## Сборка

Python 3.11+, Arial/Consolas в Windows либо DejaVu в Linux.

```sh
python -m pip install -r requirements.txt
python scripts/build.py
python scripts/check.py
python -m http.server 8000 --directory site
```

Сборка полностью заменяет только каталог `site/`, чтобы старые файлы не оставались в публикации.

В `site/downloads/` ровно два PDF A4 в альбомной ориентации:

- `assignment.pdf` — обязательное задание вместе с предметными областями;
- `guide.pdf` — дополнительная инструкция с образцом, выдаваемая по решению преподавателя.

Также доступен файл `CrystalCounter.cs`. Сайт и PDF используют одно содержание. Старые HTML-адреса перенаправляют на основные страницы и не содержат копий материалов. Старые параллельные PDF удалены.

Перед выдачей проверьте реквизиты, содержание и работу примера, установите `meta.status=ready`, затем выполните `python scripts/build.py --release`. Проверка полноты не заменяет методическую экспертизу.

## Источники и проверка

Структура учитывает [прежнюю практику](https://github.com/OlgaKraven/DKIP.PP.05-methodI); оформление основано на [визуальном шаблоне](https://github.com/OlgaKraven/2026-demo-template). Код образца скомпилирован с библиотеками Unity 6000.3.4f1. Интерактивный запуск не проверен: редактор не нашёл действующую лицензию.

Автоматическая публикация выполняется `.github/workflows/pages.yml`. Для другой специальности заменяется содержание одного комплекта, а не добавляется параллельная версия сайта.
