# Наполнение одного комплекта

Редактируйте content/course.json. Разделы: meta, assignment, areas, guide, code. Не создавайте копию модели для примера: заполненный пример и есть образец использования шаблона.

Страница имеет title, kicker и blocks. Блок имеет title, text и kind (text, note, code, diagram). Короткий шаг оформляется отдельной страницей. Полное условие и правила сдачи помещаются в assignment; индивидуальные условия — в areas. В обязательном PDF эти разделы объединяются, а на сайте размещаются отдельно.

В guide находятся объяснения, действия, статичные рисунки, программа и проверки. Отдельного повторяющего их result-раздела нет. Для другой специальности замените код полным образцом документа, расчёта или операции.

Полная программа хранится в code. Для её частей в guide используйте code_lines: [начало, конец], индексы с нуля, конец не включается. text такого блока формируется автоматически. Диапазоны вместе должны покрывать программу без пропусков и повторов.

Рисунок diagram содержит count, target и короткую подпись text. Это поясняющая схема, не снимок интерфейса Unity.

Количество вариантов определяется содержанием areas. Для 30 вариантов составьте 30 различных карточек, не тиражируйте пустые заготовки. Связь с другой практикой описывайте в условии только при необходимости.

Сборка: python scripts/build.py. Проверки: python scripts/check.py. Выдача после авторской проверки: установите meta.status=ready и выполните python scripts/build.py --release. В учебную систему загрузите assignment.pdf; guide.pdf можно выдать дополнительно. Исходные материалы, необходимые для работы, приложите там же.
